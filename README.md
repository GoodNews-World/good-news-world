# Good News World — starter app

This is the first front-end prototype for Good News World. It runs locally in a browser and is responsive for desktop and mobile.

## What works now
- Responsive home page and story cards
- Search across sample headlines, topics, and countries
- Category and country filters
- Save/unsave stories using browser local storage
- Saved stories view

## Important: sample content
The six cards are **illustrative placeholders**, not current news reports. This first version is a design and interaction prototype. The next development step is connecting permitted news feeds, adding source/date validation, and replacing the sample cards with real articles.

## Run it on your Mac
1. Download and unzip `good_news_world_starter.zip`.
2. Open the `good_news_world` folder.
3. Double-click `index.html` to open it in Safari or Chrome.

No installation or account is needed to preview the prototype.

## Next build milestone
Connect a small set of reputable, legally usable RSS/news sources through a server-side feed collector. Then add:
- article deduplication and publication-date checks
- positive/constructive story classification with transparent criteria
- short summaries that preserve caveats
- original-source links and attribution
- a scheduled refresh

Do not present generated summaries as original reporting. Keep the publisher, headline, date, and source link visible.
